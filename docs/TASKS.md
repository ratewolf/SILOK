각 PR은 관련 테스트와 실행 결과를 포함한다. 데이터 원본·DB·모델·로컬 보고서는 커밋하지 않고 재생성 명령과 요약만 공유한다. DB 스키마 또는 서비스 반환 형식을 바꾸는 PR은 영향을 받는 담당자의 리뷰를 받는다.

전체 데이터 범위(수정실록·중초본/정초본·부록 포함 여부), 프로젝트 라이선스, 외부 공개 배포 방식은 팀 결정 항목이다. 현재는 3개 왕대의 소규모 검증 데이터와 로컬 실행을 기준으로 한다.
