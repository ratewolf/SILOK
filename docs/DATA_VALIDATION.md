## 검증 범위와 발견 사항

전체 코퍼스 검증이 아니라 대표 파일 6개의 구조·메타데이터 검사다. `python -m sillok_poc.validate_data`로 재실행하며, 기존 DB 경로가 있으면 덮어쓰지 않고 종료한다. 필요하면 `--db data/validation-next.db --output reports/data-validation-next.json`처럼 새 경로를 지정한다. 원본 파일 SHA-256과 상세 통계는 로컬 JSON 보고서에 기록한다.

기존 파서가 완료된 기사 앞의 형제 노드들을 지우면서 상위의 `front/biblioData`를 삭제했다. 이 때문에 후속 기사의 왕대가 사라져 누락되거나 상위 날짜로 잘못 대체될 수 있었다. 완료된 record만 제거하도록 수정했다. 여러 기사·날짜·월에서 상속 메타데이터가 유지되는 회귀 테스트를 추가했다.

| 파일 | 기존 추출 | 수정 후 추출 | 복구 기사 |
| --- | ---: | ---: | ---: |
| 2nd_waa_101.xml | 121 | 187 | 66 |
| 2nd_wba_101.xml | 124 | 302 | 178 |
| 2nd_wda_100.xml | 136 | 686 | 550 |
| 2nd_wda_101.xml | 474 | 1,581 | 1,107 |
| 합계 | 855 | 2,756 | 1,901 |

위 4개 파일의 `level5` 기사는 수정 후 전부 추출되었으며 필수 메타데이터 누락과 파일 내부 ID 중복은 없었다. 이 결과를 나머지 파일 전체로 일반화하지 않는다.

`2nd_waa_000.xml`에는 `level3/type=T` 134건, `2nd_waa_200.xml`에는 2건이 있다. 현재 로더는 일반 재위년의 `level5`만 대상으로 하므로 이 136건은 적재 범위에서 제외된다. 서문·총서·부록의 별도 데이터 모델은 데이터 파트의 작업이다.

`data/validation-v2.db`는 수정된 파서로 태조 1392년·정종 1399년·세종 1419년 각 100건, 총 300건을 적재했다. 고유 ID 300개, `PRAGMA integrity_check=ok`를 확인했다. 기존 `data/sillok_poc.db`는 보존했다. 기존 DB는 수정 전 파서로 생성되었을 수 있으므로 후속 검증에는 새 검증 DB를 사용한다.
